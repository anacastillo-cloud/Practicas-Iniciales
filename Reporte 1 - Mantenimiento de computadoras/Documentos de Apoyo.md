# Documentos de Apoyo

---

Aquí les dejare los **Promt** que utilice para hacer el manual y el trifoliar.

> Un **Prompt** es una instrucción, contexto, parámetros o texto estructurado que se utiliza para interactuar y guiar las respuestas de un
modelo de lenguaje de Inteligencia Artificial.

## **Trifoliar:** la IA utilizada fue Gemini.

**Promt:** hola gemini, quiero que tomes el rol de una diseñadora grafica, toma en cuenta este material sera presentado para gente profesional. 
Genera una imagen que contenga un trifoliar informativo que abarque gran parte de la imagen que tenga como titulo "Guía rápida para un buen mantenimiento
de nuestra computadora", coloca informacion sobre como hacer un buen mantenimiento para nuestras computadoras. Quiero que uses tonos azules y amarillos,
también coloca imágenes que tengan que ver con la computadora y añade unas estrellas. No quiero que uses tecnicismos ni que coloques información 
que no tenga que ver con el tema, que las letras que uses sean legibles y la información sea de ayuda para el usuario.

## **Manual Técnico:** la IA utilizada fue Claude.

**Promt:** hola claude, quiero que tomes el rol de una persona experta en el mantenimiento de computadoras, toma en cuenta este material sera presentado 
para gente profesional. Genera un documento .md que sea un manual sobre como hacer el mantenimiento a nuestras computadoras; describe cada paso, resalta 
puntos importantes y coloca advertencias sobre lo que no se debe hacer o medidas a tomar en cuenta. Quiero la información sea coherente y sea de utilidad 
para el usuario. NO uses tecnicismos usa un lenguaje facil de entender para el usuario.
